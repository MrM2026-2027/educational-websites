# Educational Websites

Interactive learning websites, hosted with GitHub Pages.

| Site | Folder | Live link |
|---|---|---|
| Maths 1A Playground (Grade 1) | `maths1a/` | https://mrm2026-2027.github.io/educational-websites/maths1a/ |

Each site is a single self-contained `index.html` in its own folder. To add a new site, create a new folder with its own `index.html` and add a card for it to the home page (`index.html` at the top level).
